# Frozen artifact guide

The `artifacts/` directory contains the compact, paper-relevant outputs from
the reported experiments. It is separate from the default output paths so a
fresh clone can reproduce every stage without overwriting the frozen release.

## Included directories

| Directory | Contents |
|---|---|
| `artifacts/e1_structural_outputs/` | E1 numerical tables, summary, and figure |
| `artifacts/e2_outputs/` | E2 numerical tables, summary, and figures |
| `artifacts/e3_tabular_protocol/` | Frozen split, baseline, preprocessing, and endpoint indices |
| `artifacts/e3_tabular_controls/` | Additive/quadratic audits and diagnostics |
| `artifacts/e3_tabular_mlp/` | MLP audits, endpoint analysis, threshold surface, and diagnostics |
| `artifacts/e3_tabular_crossnet/` | CrossNet audits, summary, and diagnostics |
| `artifacts/e3_tabular_cross_architecture/` | Paired MLP/CrossNet endpoint analysis |
| `artifacts/e3_vision_protocol/` | Frozen Fashion-MNIST protocol and image panel |
| `artifacts/e3_vision_controls/` | Vision control audits and diagnostics |
| `artifacts/e3_vision_cnn/` | CNN audits, paired summaries, and diagnostics |
| `artifacts/paper_figures/` | E3a/E3b figures, values, and manifests |

Trained `.pt` checkpoints and dataset caches are not distributed. The vision
manifests retain their checkpoint hashes as provenance, while the read-only
artifact verifier deliberately skips those unused entries and verifies every
distributed non-checkpoint file.

## Release sanitization

All numerical CSV files, arrays, and plotted figures are byte-identical to the
frozen run. Two metadata-only JSON fields originally contained an absolute
execution directory; their paths were replaced by repository-relative paths.
No numerical value, endpoint identity, pass flag, or artifact hash was changed.

Legacy pilot figures and parsed tables that are not referenced by the current
manuscript and are not generated by the released scripts are excluded.

## Verify the frozen release

```bash
python tools/verify_release.py
python tools/verify_artifacts.py
```

## Regenerate paper artifacts without training

Tabular figures:

```bash
python ICLR/e3_tabular_paper_figures.py \
  --controls-dir artifacts/e3_tabular_controls \
  --mlp-dir artifacts/e3_tabular_mlp \
  --crossnet-dir artifacts/e3_tabular_crossnet \
  --out-dir regenerated/paper_figures
```

Vision figures and LaTeX tables:

```bash
python ICLR/e3_vision_paper_artifacts.py \
  --protocol-dir artifacts/e3_vision_protocol \
  --controls-dir artifacts/e3_vision_controls \
  --cnn-dir artifacts/e3_vision_cnn \
  --out-dir regenerated/paper_figures
```

The vision generator also creates LaTeX helper files; these are reproducible but intentionally not distributed.

Both commands are read-only with respect to the frozen artifacts. The
regenerated PDFs may have different metadata or byte hashes across Matplotlib
versions, while their plotted values are fixed by the distributed CSV/JSON
inputs.

`artifact_manifest_sha256.json` records the byte length and SHA-256 digest of
every distributed artifact. It should be regenerated with
`python tools/build_artifact_manifest.py` only after an intentional artifact
change.
